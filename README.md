# Stargaze
Night-sky PWA: live sky view (Hipparcos bright stars, constellation lines, planets via Astronomy Engine), AR planets via model-viewer, and a Tonight page (planets, Moon, ISS passes from CelesTrak TLE + satellite.js, meteor showers, Open-Meteo clouds).
Credits: Astronomy Engine (MIT), satellite.js (MIT), @google/model-viewer (Apache-2.0), d3-celestial data (BSD), planet textures © Solar System Scope (CC BY 4.0, based on NASA data).
